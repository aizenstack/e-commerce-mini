# E-Commerce Mini Project

Hi! This is my very first Flutter project. I am learning how to build a simple e-commerce application to understand the fundamentals of Flutter and Dart.

## 📝 What I'm Learning
- Understanding the structure of a Flutter project.
- Building simple UIs using basic widgets.
- Learning the difference between `Stateless` and `Stateful` widgets.
- Displaying a list of products.

## 🚀 Project Progress
- [ ] Create the Home Screen.
- [ ] Create the Product Detail Page.
- [ ] Learn how to navigate between pages.

## 🛠️ How to Run
If you want to run this project on your machine:
1. Make sure you have Flutter installed.
2. Run `flutter pub get` in the terminal to fetch dependencies.
3. Run `flutter run` to launch the app on your emulator or physical device.
